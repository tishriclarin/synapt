# SynapT

**Build anywhere. Never start from zero.**

Rust-first independent Android AI workspace. Automate routine organization without LLM calls, preserve working solutions through verified skills and persistent context, and unify files and project editors. Chat history and unorganized storage should not force users to repeatedly rediscover solutions. Preserve familiar ChatGPT-style interactions using supported integrations only.

Early development; not a verified application. Owner-controlled main; contributions through pull requests. License pending owner selection.
